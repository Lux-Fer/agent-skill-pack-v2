## ❓ Frequently Asked Questions

### What exactly is a "skill"?

A skill is a structured markdown file that teaches your AI agent a specific workflow. It includes trigger conditions, numbered steps with exact commands, a pitfalls section (what NOT to do), and verification steps. When you say "Debug this using systematic debugging," your agent loads the skill and follows it like a playbook.

### Do I need to be technical to use this?

You need to be comfortable with a terminal and have one of the supported AI coding agents installed. If you can run `git clone` and copy files, you're good.

### Which AI agents does this work with?

**All five:** Claude Code, Codex (OpenAI), OpenClaw, Cursor, Hermes Agent. Each has slightly different installation steps (documented in the pack), but the skill format is universal.

### What's new in V2?

V2 refines every skill with lessons from real-world production use: better commands, fewer pitfalls, improved verification steps, and broader agent compatibility. New additions include `design-md`, `excalidraw`, and `codebase-inspection`.

### Do the skills require internet access?

Most skills work offline. Only the GitHub skills (`github-pr-workflow`, `github-issues`, etc.) require internet access to talk to GitHub's API.

### Can I modify the skills?

Absolutely. The MIT license gives you full rights to modify, distribute, and sublicense. Enterprise tier includes custom skill requests — we'll build skills tailored to your workflow.

### How are skills different from system prompts or .cursorrules?

System prompts and .cursorrules are passive — they sit in the background. Skills are **active**: they load on demand when a specific task is triggered, providing detailed, step-by-step instructions. Think of system prompts as guidelines and skills as playbooks.

### Will this work with VS Code extensions like GitHub Copilot?

Skills are optimized for agentic coding tools (Claude Code, Codex, etc.) that can read and follow long-form instructions. Copilot Chat may work for some skills, but the full benefit comes from agents that execute multi-step workflows autonomously.
